# Calculadora Bet

Calculadora que distribui o valor total entre apostas para garantir retorno em qualquer resultado.

🔗 **Demo:** https://bertmartins.github.io/Bet-Calculator/

## 🛠️ Tecnologias

- HTML
- JavaScript

## 🚀 Como executar

```bash
git clone https://github.com/BertMartins/Bet-Calculator.git
cd Bet-Calculator
```

Abra o arquivo `index.html` no navegador ou acesse a demo acima.
